Shortest summary:

> Build BoardClaw as a board-aware local AI control runtime. Prove it first on
> Raspberry Pi 5 for IoT, Orange Pi 5 Plus for smart home, and Jetson Orin Nano
> for robotics, while letting users enable only the features they need and
> keeping every interface ready for single-device or multi-board deployments.
